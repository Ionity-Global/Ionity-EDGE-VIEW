About EDGE-VIEW

EDGE-VIEW is a compact, high-performance display station built on the Raspberry Pi Pico 2W. It uses PIO-based DVI output to drive a 10.1-inch IPS LCD panel, delivering smooth 640×480p60 video with 8-colour 3-bit RGB graphics. Built-in WiFi enables remote control via a TCP stream server, real-time weather updates, and AI-powered interaction.

The firmware is powered by SDK-Ionity, a custom library providing WiFi provisioning, data streaming, pixel-level drawing utilities, and branded UI components — all optimised for the Pico’s dual-core RP2350 architecture.

Stream Protocol

EDGE-VIEW runs a TCP server on port 4242. The server streams values into the key/value store and rebinds panels to slots — live, with no reflash:

{"type":"data","key":"hdr.title","value":"IO-NITY EDGE-VIEW"}
{"type":"layout","slot":"stage","panel":"clock"}
{"type":"query","what":"layout"}
{"type":"wifi","ssid":"NewNetwork","pass":"secret"}
{"type":"mode","name":"pacman"}
{"type":"ping"} · {"type":"reboot"}
